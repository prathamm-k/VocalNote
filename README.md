# VocalNote

*Turn Any PDF Into a Beautiful, Local Podcast—Offline, Secure, Fast, and Optimized.*

VocalNote is an offline, privacy-focused AI web application that transforms standard PDF documents into engaging, natural-sounding two-speaker podcast conversations. It runs entirely on your local machine—no data ever leaves your device, and no internet connection or API keys are required after setup.

---

## Project Motivation
VocalNote was built to provide students, researchers, professors, and professionals with a fast, private, and offline alternative to cloud-hosted document-to-speech services. By designing a pipeline that runs locally on edge devices, the project ensures complete security for sensitive documents while demonstrating how modern AI applications can be optimized for consumer hardware. 

This project explores the end-to-end lifecycle of local AI engineering—from PDF text extraction and advanced local LLM inference to text-to-speech synthesis and premium, responsive user experience design.

**Future Roadmap:**
- User authentication and accounts.
- Database storage for saving transcripts, uploaded files, and generated podcasts.
- Scalability optimizations for hosting local workloads or distributed edge inference.

## Project Features & Architecture

### 🎙️ Pipeline v2 Optimizations
The backend pipeline (located in [podcast_workflow.py](file:///Users/prathamkairamkonda/Developer/Projects/NoteBookQwen-CPU/backend/podcast_workflow.py)) has been significantly optimized for speed and reliability, featuring:

*   **Hardware Auto-Detection & Apple Silicon Acceleration:** On initialization, VocalNote checks the host environment. If running on Apple Silicon macOS with MPS support, it automatically configures a Metal-accelerated device (`mps`) and offloads LLM layers to the GPU (`n_gpu_layers = -1`). On Intel Macs and other platforms, it defaults to CPU execution optimized with multi-threading (halving the logical CPU cores to prevent lockups).
*   **Model Caching & Warmup:** Model files are lazy-loaded and cached in-memory (`self.llm_preprocess`, `self.llm_transcript`, `self.kpipeline`) on the first request. Subsequent generations reuse the loaded models, eliminating the 15–20 second loading overhead per request found in typical sequential pipelines.
*   **Merged LLM Workflow:** The transcript generation and rewrite steps are combined into a single structured inference pass. By skipping redundant intermediate LLM calls, the time spent in text generation has been reduced by minutes.
*   **Direct NumPy Audio Concatenation:** Individual speaker chunks generated by the Kokoro TTS engine are concatenated directly as high-performance NumPy arrays. They are written to a single output WAV file at the end of the pipeline, avoiding slow file-append operations or multiple disk writes.
*   **Optimal Character Chunking:** PDF documents are preprocessed and cleaned in parallelizable, 3000-character chunks to fit local LLM context limits and maintain high token generation throughput.

### 🎨 Culturally Authentic Indian Design System
The frontend (located in the [frontend/](file:///Users/prathamkairamkonda/Developer/Projects/NoteBookQwen-CPU/frontend) directory) features an elegant, warm, and responsive interface inspired by modern Indian art and aesthetics:
*   **Color Palette:** Curated using natural, warm tones including Saffron (`#FF9933`), Turmeric (`#D4A843`), Terracotta (`#C2703E`), Jaipur Tile Blue, and deep Charcoal backgrounds.
*   **Typography:** Merges modern visual flair (Outfit and Noto Sans) with classical Devanagari script accents (Tiro Devanagari Hindi) for section titles.
*   **Visual Motifs:** Subtle background overlays of Jaipur blue pottery, Mughal arch-styled feature cards, and slow-rotating mandala loading indicators.
*   **Micro-Animations:** Interactive status bars utilizing a traditional "diya lamp" metaphor—complete with a flickering flame animation during processing that transitions to a warm, steady glow on success.

## Setup & Installation

First, clone the repository to your local machine:
```bash
git clone https://github.com/prathamm-k/VocalNote.git
cd VocalNote
```

You can run VocalNote using either **Docker** (recommended) or via a **Traditional Local Setup**. Both methods will automatically download the required 4GB LLM models to your `~/Downloads/VocalNote_models` folder on the first run, keeping your repository lightweight!

### Option A: Docker Setup (Recommended)
The easiest way to run the application is using Docker. This avoids needing to install Python, Node.js, or manage virtual environments.

1. Ensure [Docker Desktop](https://www.docker.com/products/docker-desktop/) is installed and running.
2. In the root of the project, run:
```bash
docker compose up --build
```
3. Docker will build the containers, auto-download the models to your PC, and start both servers.
4. Open [http://localhost:2000](http://localhost:2000) in your browser.

*Note: Changes made to the code will instantly reflect in the running containers thanks to live volume mounting.*

### Option B: Traditional Local Setup

If you prefer to run the services manually in your terminal:

**1. Backend Setup (FastAPI)**
Activate the virtual environment, install dependencies, and run the backend server:
```bash
cd backend
python -m venv venv3.11
source venv3.11/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
uvicorn api:app --reload --host 0.0.0.0 --port 9000
```
*The FastAPI backend will run at `http://localhost:9000`.*

**2. Frontend Setup (React + Vite)**
Open a **second terminal window**, install dependencies, and spin up the Vite development server:
```bash
cd frontend
npm install
npm run dev
```
*The frontend development server will launch at [http://localhost:2000](http://localhost:2000).*

## API Endpoints Reference

### FastAPI Backend (`api.py` on port `9000`)
*   **`POST /upload-pdf`**
    *   Uploads a PDF file and caches it on the server temp workspace.
*   **`POST /generate-podcast`**
    *   Accepts optional PDF file uploads (supporting single-request flows). Runs the entire document-to-speech pipeline and returns a streamable WAV file.
*   **`GET /download-podcast`**
    *   Fetches the last successfully generated podcast WAV file.

## Troubleshooting & FAQ

*   **Llama-cpp / Kokoro Error (Apple Silicon):** Ensure that your PyTorch/Metal tools are correctly configured. If Metal acceleration is active, you will see `Detected Apple Silicon (arm64). Enabling Metal & MPS acceleration.` in the backend server logs.
*   **Model Files Missing:** VocalNote attempts to automatically download models to the `models/` directory (or `~/Downloads/VocalNote_models` if running via Docker). If the auto-download fails, manually download the models and place them in the correct folder:
    *   `Qwen3-1.7B-Q8_0.gguf`
    *   `qwen2.5-3b-instruct-q4_k_m.gguf`
*   **Backend Unreachable:** If the React interface shows a connection error, verify that the FastAPI backend is running on port `9000` (`uvicorn api:app ...`).
*   **Virtual Environment Issue:** Ensure you have activated `venv3.11` via `source venv3.11/bin/activate` before running your python terminal commands.
